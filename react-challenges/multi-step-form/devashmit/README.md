# ⚛️ Multi-step Registration Form [REACT] — Day 6

**Issue:** [#256](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/256) | Week 1 | Intermediate

## 📋 Description

A multi-step registration form built with React. 3 steps: Personal Info → Account Setup → Review & Submit. Progress bar, validation per step, and animated transitions between steps.

## ✨ Features

- Step 1: Name, email, phone
- Step 2: Username, password, confirm password
- Step 3: Review all inputs before submit
- Progress bar showing current step
- Per-step validation before advancing
- Animated step transitions
- Final success screen

## 🧠 Concepts Practiced

`useState` · `Form validation` · `Multi-step UX` · `Conditional rendering`

## 🚀 How to Run

```bash
npm install && npm run dev
```
