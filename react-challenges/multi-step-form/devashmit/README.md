# ⚛️ Multi-step Registration Form — Day 13 React Challenge

**Issue:** [#322](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/322) | Week 2 | Intermediate

## 📋 Description

A multi-step registration form built with React. 3 steps: Personal Info → Account Setup → Review & Submit. Progress bar, per-step validation, animated transitions, final success screen.

## ✨ Features
- Step 1: Name, email, phone
- Step 2: Username, password, confirm password
- Step 3: Review all inputs before submit
- Progress bar showing current step
- Per-step validation before advancing
- Success screen on submit

## 🚀 How to Run
```bash
npm install && npm run dev
```
