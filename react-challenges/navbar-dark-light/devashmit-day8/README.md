# ⚛️ Responsive Navbar with Dark/Light Mode — Day 8 React Challenge

**Issue:** [#275](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/275) | Week 2 | Beginner

## 📋 Description

A fully responsive React Navbar with hamburger menu for mobile and dark/light mode toggle using `useState` + CSS variables. Theme persists in `localStorage` across page refreshes.

## ✨ Features

- Responsive hamburger menu for mobile
- Dark/Light mode toggle with `useState`
- CSS variables for instant theme switching
- Theme persisted in `localStorage`
- Smooth transitions
- Components: `<Navbar>`, `<NavLinks>`, `<ThemeToggle>`

## 🧠 Concepts Practiced

`useState` · `CSS Variables` · `localStorage` · `Responsive design`

## 🚀 How to Run

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)
