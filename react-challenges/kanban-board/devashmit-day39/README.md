# ⚛️ Kanban Task Board with Drag & Drop — Day 39 React Challenge

**Issue:** [#537](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/537) | Week 6 | Advanced

## 📋 Description

Kanban board with To Do / In Progress / Done columns. HTML5 Drag & Drop API. `useReducer` for state. `localStorage` persistence.

## ✨ Features
- 3 columns: To Do, In Progress, Done
- Native HTML5 Drag & Drop (no library)
- Add tasks with title + description
- Delete tasks
- `useReducer` + `localStorage`

## 🚀 How to Run
```bash
npm install && npm run dev
```
Press Ctrl+K to open command palette (or drag tasks between columns).
