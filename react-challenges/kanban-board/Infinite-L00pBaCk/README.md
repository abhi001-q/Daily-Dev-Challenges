# ⚛️ Day 53: Kanban Task Board with Drag & Drop [REACT]

I have successfully designed and built the Kanban Board UI based on the advanced challenge requirements.

## What was built
* **Drag and Drop API:** Used the native HTML5 Drag and Drop API to move tasks between columns.
* **State Management:** Used React `useReducer` to manage complex column and task states cleanly.
* **Persistence:** Added `localStorage` integration so the board state is saved automatically.
* **Modern Unique IDs:** Utilized `crypto.randomUUID()` to guarantee collision-free task creation.
* **Premium Dark UI:** Designed a stunning dark mode interface with glassmorphism, gradients, and micro-animations.

## Tech Stack
* React + Vite
* HTML5 Drag and Drop API
* Vanilla CSS Variables & Flexbox

## How to run locally
```bash
npm install
npm run dev
```
