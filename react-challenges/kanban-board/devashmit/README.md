# ⚛️ Kanban Task Board with Drag & Drop — Day 11 React Challenge

**Issue:** [#304](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/304) | Week 2 | Advanced

## 📋 Description

A Kanban board with To Do / In Progress / Done columns. Tasks are draggable between columns using the HTML5 Drag & Drop API. `useReducer` for board state. Persists to `localStorage`.

## ✨ Features

- 3 columns: To Do, In Progress, Done
- Drag & Drop tasks between columns (HTML5 native API)
- Add new tasks with title + optional description
- Delete tasks
- `useReducer` for state management
- `localStorage` persistence — survives refresh
- Task count badge per column

## 🧠 Concepts Practiced

`Drag & Drop API` · `useReducer` · `localStorage` · `Composition` · `crypto.randomUUID()`

npm install
npm run dev
