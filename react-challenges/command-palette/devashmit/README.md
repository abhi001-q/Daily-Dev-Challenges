# ⚛️ Command Palette (Ctrl+K Search) — Day 14 React Challenge

**Issue:** [#331](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/331) | Week 2 | Advanced

## 📋 Description

A VS Code-style command palette triggered by Ctrl+K. Fuzzy search through commands, keyboard navigation (↑↓ Enter Esc), and executes commands on selection.

## ✨ Features
- Ctrl+K / Cmd+K to open
- Fuzzy search through 20+ commands
- Keyboard navigation (↑↓ to move, Enter to execute, Esc to close)
- Click to execute
- Command categories with icons
- Smooth animation

## 🚀 How to Run
```bash
npm install && npm run dev
```
Press Ctrl+K to open the palette.
