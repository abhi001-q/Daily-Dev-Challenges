# ⚛️ Command Palette (Ctrl+K Search) — Day 28 React Challenge

**Issue:** [#446](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/446) | Week 4 | Advanced

## 📋 Description

VS Code-style command palette triggered by Ctrl+K. Fuzzy search through 21 commands, keyboard navigation (↑↓ Enter Esc), executes commands on selection.

## 🚀 How to Run
```bash
npm install && npm run dev
```
Press **Ctrl+K** to open.
