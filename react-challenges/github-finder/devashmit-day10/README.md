# ⚛️ GitHub Profile Finder — Day 10 React Challenge

**Issue:** [#295](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/295) | Week 2 | Intermediate

## 📋 Description

Fetch a GitHub user's public profile from the GitHub REST API. Shows avatar, bio, repo count, followers, and top 5 repos. Loading skeletons and error handling for invalid usernames. Custom `useFetch` hook.

## ✨ Features
- Search any GitHub username
- Avatar, name, bio, location, followers, following, repos
- Top 5 repos sorted by stars
- Loading skeleton UI
- Error handling
- Custom `useFetch` hook

## 🚀 How to Run
```bash
npm install && npm run dev
```
