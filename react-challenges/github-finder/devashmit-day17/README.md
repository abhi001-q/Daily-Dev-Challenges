# ⚛️ GitHub Profile Finder — Day 17 React Challenge

**Issue:** [#356](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/356) | Week 3 | Intermediate

## 📋 Description

Fetches a GitHub user's public profile from the GitHub REST API. Shows avatar, bio, repo count, followers, and top 5 repos. Loading skeletons and error handling. Custom `useFetch` hook.

## ✨ Features
- Search any GitHub username
- Avatar, name, bio, location, followers, following, repos
- Top 5 repos sorted by stars
- Loading skeleton UI
- Error handling
- Custom `useFetch` hook

## 🚀 How to Run
```bash
npm install && npm run dev
```
