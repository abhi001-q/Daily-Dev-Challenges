# GitHub Profile Finder

A beautiful, glassmorphism-themed React application that fetches and displays a user's GitHub profile and their top 5 most recently updated repositories using the GitHub REST API.

## Features
- **Fetch API & Custom Hooks:** Built with a custom `useFetch` hook to cleanly manage API state and logic.
- **Top 5 Repositories:** Displays the user's latest active repositories.
- **Loading Skeletons:** Animated skeleton loaders provide a smooth user experience while data is being fetched.
- **Error Handling:** Gracefully handles invalid usernames with clear error messages.
- **Glassmorphism UI:** Stunning dark mode interface with mesh gradients and glass-like panels.
