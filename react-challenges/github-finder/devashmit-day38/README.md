# ⚛️ GitHub Profile Finder — Day 38 React Challenge

**Issue:** [#528](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/528) | Week 6 | Intermediate

## 📋 Description

Fetches a GitHub user's public profile from the GitHub REST API. Shows avatar, bio, repo count, followers, top 5 repos. Loading skeletons and error handling. Custom `useFetch` hook.

## 🚀 How to Run
```bash
npm install && npm run dev
```
