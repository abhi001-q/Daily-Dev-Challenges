# ⚛️ Pomodoro Timer with useEffect — Day 9 React Challenge

**Issue:** [#285](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/285) | Week 2 | Intermediate

## 📋 Description

A Pomodoro timer (25 min work / 5 min break) built with React. Uses `useEffect` + `setInterval` for countdown with proper cleanup. `useReducer` for cleaner state management. Start, pause, reset, and session counter.

## ✨ Features
- 25-min work / 5-min break cycle
- Start, Pause, Reset controls
- Session counter
- Interval cleanup on unmount
- `useReducer` for state management
- Visual mode indicator (Work/Break)

## 🚀 How to Run
```bash
npm install && npm run dev
```
