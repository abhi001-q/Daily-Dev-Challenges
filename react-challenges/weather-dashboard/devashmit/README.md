# ⚛️ Real-time Weather Dashboard — Day 12 React Challenge

**Issue:** [#313](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/313) | Week 2 | Intermediate

## 📋 Description

A real-time weather dashboard using the OpenWeatherMap API. Shows current weather and 5-day forecast. Custom `useWeather` hook, loading skeleton, °C/°F toggle.

## ✨ Features
- Current weather: temp, humidity, wind, condition
- 5-day forecast cards
- Search by city name
- Loading skeleton UI
- °C / °F toggle
- Error handling for invalid cities
- Custom `useWeather` hook

## 🚀 How to Run
```bash
npm install && npm run dev
```
Get a free API key at [openweathermap.org](https://openweathermap.org/api) and set it in `src/config.js`.
