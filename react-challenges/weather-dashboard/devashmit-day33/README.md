# ⚛️ Real-time Weather Dashboard — Day 33 React Challenge

**Issue:** [#487](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/487) | Week 5 | Intermediate

## 📋 Description

Real-time weather dashboard using OpenWeatherMap API. Current weather + 5-day forecast. Custom `useWeather` hook, skeleton, °C/°F toggle, error handling.

## 🚀 How to Run
```bash
npm install && npm run dev
```
Set your API key in `src/config.js`.
