# ⚛️ Real-time Weather Dashboard — Day 19 React Challenge

**Issue:** [#373](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/373) | Week 3 | Intermediate

## 📋 Description

Real-time weather dashboard using OpenWeatherMap API. Current weather + 5-day forecast. Custom `useWeather` hook, skeleton, °C/°F toggle.

## 🚀 How to Run
```bash
npm install && npm run dev
```
Get API key at [openweathermap.org](https://openweathermap.org/api) and set it in `src/config.js`.
