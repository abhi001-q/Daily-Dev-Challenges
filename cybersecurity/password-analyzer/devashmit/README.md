# 🔐 Password Strength Analyzer — Day 9 Cybersecurity Challenge

**Issue:** [#289](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/289) | Week 2 | Beginner

## 📋 Description

Analyzes password strength: length, character mix, entropy, and checks against common passwords. Returns a score out of 100 with specific improvement suggestions.

## ✨ Features
- Score 0–100 based on: length, uppercase, lowercase, digits, symbols
- Common password check (top 1000 list built-in)
- Entropy calculation
- Specific improvement suggestions
- CLI with interactive prompt

## 🚀 How to Run
```bash
python analyzer.py
```
