# 🔐 Password Strength Analyzer — Day 14 Cybersecurity Challenge

**Issue:** [#335](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/335) | Week 2 | Beginner

## 📋 Description

Analyzes password strength: length, character mix, entropy, common password check. Returns score 0–100 with specific improvement suggestions.

## ✨ Features
- Score 0–100 (length + charset + entropy)
- Common password detection
- Entropy calculation
- Specific improvement suggestions
- Interactive CLI

## 🚀 How to Run
```bash
python analyzer.py
```
