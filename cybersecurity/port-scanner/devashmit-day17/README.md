# 🔐 Multi-threaded Port Scanner — Day 17 Cybersecurity Challenge

**Issue:** [#360](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/360) | Week 3 | Beginner

## 📋 Description

Multi-threaded port scanner using `socket` + `threading`. Scans IP for open ports, displays service names, exports report.

> ⚠️ Only scan systems you own or have permission to scan.

## ✨ Features
- Multi-threaded (configurable)
- 0.5s timeout per port
- Service name lookup
- `scan_report.txt` export

## 🚀 How to Run
```bash
python port_scanner.py
```
