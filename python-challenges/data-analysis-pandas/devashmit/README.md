## 📋 Description

A data analysis script using Pandas and Matplotlib. Loads a CSV dataset, cleans it, performs exploratory analysis, and generates visualizations including bar charts, histograms, and correlation heatmaps.

## ✨ Features

- Load and inspect CSV dataset
- Handle missing values and duplicates
- Descriptive statistics (mean, median, std, etc.)
- Group-by aggregations
- Bar chart, histogram, correlation heatmap visualizations
- Saves plots to `output/` folder

## 🧠 Concepts Practiced

`pandas` · `matplotlib` · `seaborn` · `data cleaning` · `EDA`

## 🚀 How to Run

```bash
pip install pandas matplotlib seaborn
python analysis.py
```
