# 🧠 Data Analysis with Pandas — Day 10 Python Challenge

**Issue:** [#296](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/296) | Week 2 | Intermediate

## 📋 Description

EDA script using Pandas and Matplotlib on a sample sales CSV. Cleans data, computes descriptive statistics, group-by aggregations, and generates bar chart, histogram, and correlation heatmap.

## ✨ Features
- Load & inspect CSV data
- Handle missing values and duplicates
- Descriptive statistics
- Group-by aggregations
- Bar chart, histogram, correlation heatmap
- Saves plots to `output/`

## 🚀 How to Run
```bash
pip install pandas matplotlib seaborn
python analysis.py
```
