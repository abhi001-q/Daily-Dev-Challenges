# 🐍 CLI Password Manager — Day 33 Python Challenge

**Issue:** [#488](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/488) | Week 5 | Intermediate

## 📋 Description

Terminal password manager with add/get/list/delete. Fernet encryption + PBKDF2HMAC key derivation. `getpass` for secure input.

## 🚀 How to Run
```bash
pip install cryptography
python manager.py add
python manager.py list
```
