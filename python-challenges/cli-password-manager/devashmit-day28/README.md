# 🐍 CLI Password Manager — Day 28 Python Challenge

**Issue:** [#447](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/447) | Week 4 | Intermediate

## 📋 Description

Terminal password manager with add/get/list/delete commands. Fernet encryption + PBKDF2HMAC key derivation. `getpass` for secure input. Encrypted local JSON vault.

## 🚀 How to Run
```bash
pip install cryptography
python manager.py add
python manager.py list
```
