# 🐍 Web Scraper with BeautifulSoup — Day 17 Python Challenge

**Issue:** [#357](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/357) | Week 3 | Intermediate

## 📋 Description

Scrapes quotes.toscrape.com — all quotes, authors, and tags across all pages. Auto-pagination. Saves to `.json` and `.csv`.

## ✨ Features
- All pages via automatic pagination
- Extracts: text, author, tags
- Exports `quotes.json` and `quotes.csv`
- `time.sleep(1)` between requests

## 🚀 How to Run
```bash
pip install requests beautifulsoup4
python scraper.py
```
