# 🟨 Vanilla JS Todo App — Day 10 JavaScript Challenge

**Issue:** [#300](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/300) | Week 2 | Beginner

## 📋 Description

Zero-framework todo app. Add, delete, mark complete, filter by status, persist with localStorage. Event delegation on list container.

## ✨ Features
- Add / delete / toggle complete
- Filter: All / Active / Completed
- localStorage persistence
- Event delegation
- Item count display

## 🚀 How to Run
Open `index.html` in any browser.
