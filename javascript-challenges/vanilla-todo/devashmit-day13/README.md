# 🟨 Vanilla JS Todo App — Day 13 JavaScript Challenge

**Issue:** [#327](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/327) | Week 2 | Beginner

## 📋 Description

Zero-framework todo app. Add, delete, mark complete, filter by status, localStorage persistence. Event delegation on list container.

## ✨ Features
- Add / delete / toggle complete
- Filter: All / Active / Completed
- localStorage persistence
- Event delegation
- Item count

## 🚀 How to Run
Open `index.html` in any browser.
