# 🟨 Infinite Scroll Gallery — Day 17 JavaScript Challenge

**Issue:** [#361](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/361) | Week 3 | Intermediate

## 📋 Description

Infinite scroll gallery using Unsplash API. IntersectionObserver loads next page automatically. Masonry layout, loading spinner, lightbox on click.

## ✨ Features
- IntersectionObserver (performant)
- Masonry CSS columns
- Loading spinner
- Lightbox + Esc to close

## 🚀 How to Run
Replace `YOUR_ACCESS_KEY` in `script.js`, then open `index.html`.
