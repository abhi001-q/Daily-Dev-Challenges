# 🟨 Infinite Scroll Gallery — Day 14 JavaScript Challenge

**Issue:** [#336](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/336) | Week 2 | Intermediate

## 📋 Description

Infinite scroll image gallery using Unsplash API. IntersectionObserver detects scroll end and auto-fetches next page. Masonry layout, loading spinner, lightbox on click.

## ✨ Features
- 12 images initially, auto-loads more on scroll
- IntersectionObserver (performant, no scroll events)
- Masonry CSS columns layout
- Loading spinner
- Lightbox on image click (Esc to close)

## 🚀 How to Run
1. Get API key from [unsplash.com/developers](https://unsplash.com/developers)
2. Replace `YOUR_ACCESS_KEY` in `script.js`
3. Open `index.html`
