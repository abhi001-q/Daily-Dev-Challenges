# 🟨 Infinite Scroll Gallery [JAVASCRIPT] — Day 5

**Issue:** [#251](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/251) | Week 1 | Intermediate

## 📋 Description

An infinite scroll image gallery using the Unsplash API. Loads images in batches using IntersectionObserver. Includes masonry-style layout, loading spinner, and lightbox on click.

## ✨ Features

- Loads 12 images initially from Unsplash API
- IntersectionObserver detects scroll end and loads next page
- Masonry-style CSS grid layout
- Loading spinner during fetch
- Lightbox modal on image click (ESC to close)
- Lazy image loading

## 🧠 Concepts Practiced

`IntersectionObserver` · `Fetch API` · `Masonry layout` · `Lightbox`

## 🚀 How to Run

1. Get a free API key at [unsplash.com/developers](https://unsplash.com/developers)
2. Replace `YOUR_ACCESS_KEY` in `script.js`
3. Open `index.html` in browser
