# 🟨 Real-time Search Filter with Highlighting [JAVASCRIPT] — Day 6

**Issue:** [#261](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/261) | Week 1 | Beginner

## 📋 Description

A searchable list of 50+ countries with real-time filtering, highlighted matched text using regex + `<mark>`, and continent filter chips. Input is debounced with `setTimeout`.

## ✨ Features

- 50+ countries with continents
- Real-time filter as you type (200ms debounce)
- Matched text highlighted with `<mark>` via regex
- Filter chips: All, Asia, Europe, Americas, Africa, Oceania
- Result count display

## 🧠 Concepts Practiced

`Debouncing` · `Array filter/map` · `Regex highlight` · `Filter chips`

## 🚀 How to Run

Open `index.html` in any browser — no build step.
