# 🟨 Real-time Search Filter with Highlighting — Day 9 JavaScript Challenge

**Issue:** [#290](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/290) | Week 2 | Beginner

## 📋 Description

Searchable list of 50+ countries with real-time filtering, highlighted matched text using regex + `<mark>`, category filter chips, and debounced input.

## ✨ Features
- 50+ countries with continents
- Real-time filter (200ms debounce)
- Regex highlight with `<mark>`
- Continent filter chips
- Result count

## 🚀 How to Run
Open `index.html` in any browser.
