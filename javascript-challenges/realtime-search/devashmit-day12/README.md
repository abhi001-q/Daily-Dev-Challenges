# 🟨 Real-time Search Filter with Highlighting — Day 12 JavaScript Challenge

**Issue:** [#318](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/318) | Week 2 | Beginner

## 📋 Description

Searchable list of 50+ countries with real-time filtering, matched text highlighted via regex + `<mark>`, and continent filter chips. Debounced with `setTimeout`.

## ✨ Features
- 50+ countries with continent data
- Real-time filter (200ms debounce)
- Regex highlight with `<mark>`
- Continent filter chips
- Result count display

## 🚀 How to Run
Open `index.html` in any browser.
