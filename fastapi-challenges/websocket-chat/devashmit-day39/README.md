# ⚡ Real-time Chat with WebSockets — Day 39 FastAPI Challenge

**Issue:** [#540](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/540) | Week 6 | Advanced

## 📋 Description

Real-time chat using FastAPI WebSockets. Multiple rooms, broadcast, join/leave notifications. Minimal HTML frontend at `GET /`.

## 🚀 How to Run
```bash
pip install fastapi uvicorn && uvicorn main:app --reload
```
Open http://localhost:8000 in multiple browser tabs.
