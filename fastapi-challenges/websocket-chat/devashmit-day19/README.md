# ⚡ Real-time Chat with WebSockets — Day 19 FastAPI Challenge

**Issue:** [#376](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/376) | Week 3 | Advanced

## 📋 Description

Real-time chat using FastAPI WebSockets. Multiple rooms, broadcast, join/leave notifications. Minimal HTML frontend at `GET /`.

## 🚀 How to Run
```bash
pip install fastapi uvicorn
uvicorn main:app --reload
```
Open http://localhost:8000 in multiple browser tabs.
