# ⚡ File Upload & Image Processing API — Day 28 FastAPI Challenge

**Issue:** [#449](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/449) | Week 4 | Intermediate

## 📋 Description

FastAPI image upload API. Validates type/size, resizes to 3 sizes (thumbnail/medium/large) using Pillow. Returns processed URLs.

## 🚀 How to Run
```bash
pip install fastapi uvicorn pillow python-multipart
uvicorn main:app --reload
```
