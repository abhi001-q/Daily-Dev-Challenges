# ⚡ File Upload & Image Processing API — Day 33 FastAPI Challenge

**Issue:** [#490](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/490) | Week 5 | Intermediate

## 📋 Description

FastAPI image upload API. Validates type/size, resizes to thumbnail/medium/large using Pillow. Returns processed URLs.

## 🚀 How to Run
```bash
pip install fastapi uvicorn pillow python-multipart
uvicorn main:app --reload
```
