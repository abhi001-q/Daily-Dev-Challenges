# ⚡ File Upload & Image Processing API — Day 38 FastAPI Challenge

**Issue:** [#531](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/531) | Week 6 | Intermediate

## 📋 Description

FastAPI image upload API. Validates type/size, resizes to thumbnail/medium/large using Pillow. Returns processed URLs.

## 🚀 How to Run
```bash
pip install fastapi uvicorn pillow python-multipart
uvicorn main:app --reload
```
