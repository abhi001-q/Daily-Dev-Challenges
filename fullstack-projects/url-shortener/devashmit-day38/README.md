# 🚀 URL Shortener with Click Analytics — Day 38 Fullstack Challenge

**Issue:** [#534](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/534) | Week 6 | Advanced

## 📋 Description

Bitly-style URL shortener. FastAPI + SQLite backend tracks clicks. React frontend with form, short link, copy-to-clipboard, analytics table.

## 🚀 How to Run
```bash
cd backend && pip install fastapi uvicorn && uvicorn main:app --reload
cd frontend && npm install && npm run dev
```
