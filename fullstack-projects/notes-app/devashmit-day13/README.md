# 🚀 Full-stack Notes App (React + FastAPI) — Day 13 Fullstack Challenge

**Issue:** [#328](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/328) | Week 2 | Intermediate

## 📋 Description

End-to-end note-taking app. FastAPI + SQLite CRUD backend. React frontend with create/edit forms, list view, React Router. Connected via Fetch API with CORS.

## ✨ Features
**Backend:** Full CRUD `/notes`, SQLite, CORSMiddleware
**Frontend:** Notes list, detail, create/edit, delete, React Router

## 🚀 How to Run
```bash
# Backend
cd backend && pip install fastapi uvicorn && uvicorn main:app --reload
# Frontend
cd frontend && npm install && npm run dev
```
