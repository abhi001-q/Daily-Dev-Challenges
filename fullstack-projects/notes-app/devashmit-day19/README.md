# 🚀 Full-stack Notes App (React + FastAPI) — Day 19 Fullstack Challenge

**Issue:** [#379](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/379) | Week 3 | Intermediate

## 📋 Description

End-to-end note-taking app. FastAPI + SQLite CRUD. React frontend with create/edit forms, list view, React Router, Fetch API.

## 🚀 How to Run
```bash
cd backend && pip install fastapi uvicorn && uvicorn main:app --reload
cd frontend && npm install && npm run dev
```
