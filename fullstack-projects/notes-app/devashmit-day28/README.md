# 🚀 Full-stack Notes App (React + FastAPI) — Day 28 Fullstack Challenge

**Issue:** [#452](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/452) | Week 4 | Intermediate

## 📋 Description

End-to-end note-taking app. FastAPI + SQLite CRUD. React frontend with create/edit forms, list view, React Router.

## 🚀 How to Run
```bash
cd backend && pip install fastapi uvicorn && uvicorn main:app --reload
cd frontend && npm install && npm run dev
```
