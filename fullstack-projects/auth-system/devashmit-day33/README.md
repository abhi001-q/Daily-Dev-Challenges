# 🚀 JWT Auth System (React + FastAPI) — Day 33 Fullstack Challenge

**Issue:** [#493](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/493) | Week 5 | Advanced

## 📋 Description

Complete auth: Register, Login, protected Dashboard, Logout. FastAPI + JWT + bcrypt. React frontend. Token in httpOnly cookie.

## 🚀 How to Run
```bash
cd backend && pip install fastapi uvicorn python-jose passlib[bcrypt] python-multipart
uvicorn main:app --reload
cd frontend && npm install && npm run dev
```
