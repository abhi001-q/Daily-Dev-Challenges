# 🎨 Banking Dashboard UI — Day 12 UI/UX Challenge

**Issue:** [#315](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/315) | Week 2 | Intermediate

## 📋 Description

Finance dashboard UI: account balance card, recent transactions list, spending chart (CSS bars), quick action buttons. Full dark/light mode. WCAG AA contrast ratios.

## ✨ Features
- Balance cards with masked card numbers
- Transactions list (green=income, red=expense)
- CSS spending bar chart
- Quick action buttons
- Dark / Light mode toggle (localStorage)
- WCAG AA contrast ratios

## 🚀 How to Run
Open `index.html` in any browser.
