# 🎨 Mini Design System — Day 14 UI/UX Challenge

**Issue:** [#333](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/333) | Week 2 | Advanced

## 📋 Description

Mini design system with color palette, typography scale (6 sizes), spacing scale, and 5 components: Button (3 variants), Input, Card, Badge, Alert. CSS custom properties as design tokens.

## ✨ Components
- **Button** — primary, secondary, ghost variants + disabled + sm size
- **Input** — default and error state
- **Card** — header, body, footer
- **Badge** — success, warning, danger, info, default
- **Alert** — 4 types

## 🚀 How to Run
Open `index.html` in any browser.
