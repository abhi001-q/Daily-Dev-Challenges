# 🎨 Mini Design System — Day 9 UI/UX Challenge

**Issue:** [#287](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/287) | Week 2 | Advanced

## 📋 Description

A mini design system with color palette, typography scale (6 sizes), spacing scale, and 5 documented components: Button (3 variants), Input, Card, Badge, Alert. Built with CSS custom properties as design tokens.

## ✨ Components
- **Button** — primary, secondary, ghost variants
- **Input** — with label, placeholder, error state
- **Card** — with header, body, footer
- **Badge** — success, warning, danger, info
- **Alert** — 4 types with dismiss

## 🚀 How to Run
Open `index.html` in any browser.
