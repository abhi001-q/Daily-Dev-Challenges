# [UIUX] Mobile App UI - Habit Tracker

## Description
A mobile-first habit tracker interface designed for the Day 53 challenge.
Features include:
- A weekly calendar ribbon
- Daily habit cards with SVG progress rings
- Bottom navigation with a prominent FAB (Floating Action Button)
- Minimum 44x44px touch targets for optimal thumb-zone usability.
- Built using HTML, Vanilla CSS, and minimal JS for interaction.
