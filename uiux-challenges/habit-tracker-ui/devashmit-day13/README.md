# 🎨 Mobile App UI — Habit Tracker — Day 13 UI/UX Challenge

**Issue:** [#324](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/324) | Week 2 | Intermediate

## 📋 Description

Mobile-first (375px) habit tracker UI: daily checklist, weekly streak calendar, SVG progress ring per habit, bottom navigation bar. All touch targets ≥ 44×44px.

## ✨ Features
- Daily habit checklist (tap to complete)
- Weekly streak calendar
- SVG progress ring per habit
- Bottom navigation bar
- Mobile-first at 375px
- 44×44px minimum touch targets

## 🚀 How to Run
Open `index.html` in any browser (best at 375px width).
