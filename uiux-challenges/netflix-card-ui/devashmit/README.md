# 🎨 Netflix-style Card UI — Day 10 UI/UX Challenge

**Issue:** [#297](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/297) | Week 2 | Beginner

## 📋 Description

Netflix-style movie card UI with hover zoom + overlay, genre badges, rating, and horizontal scroll row with scroll snap.

## ✨ Features
- Card hover zoom + info overlay
- Genre badge chips
- Star rating display
- Horizontal scroll row with snap
- Dark theme
- Smooth CSS transitions (no JS)

## 🚀 How to Run
Open `index.html` in any browser.
