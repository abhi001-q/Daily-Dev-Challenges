# 🎨 Netflix-style Card UI [UIUX] — Day 5

**Issue:** [#248](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/248) | Week 1 | Beginner

## 📋 Description

A Netflix-style movie/show card UI with hover effects, genre badges, rating display, and a horizontal scroll row. Clean dark theme with smooth CSS transitions.

## ✨ Features

- Netflix-style card with hover zoom + overlay
- Genre badge chips
- Star rating display
- Horizontal scroll row with snap
- Dark theme throughout
- Smooth CSS transitions (no JS needed)
- Fully responsive

## 🧠 Concepts Practiced

`CSS hover effects` · `Overlay transitions` · `Scroll snap` · `Card layouts`

## 🚀 How to Run

Open `index.html` directly in any browser.
