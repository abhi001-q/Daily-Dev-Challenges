# 🎨 Personal Portfolio Landing Page [UIUX] — Day 6

**Issue:** [#258](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/258) | Week 1 | Beginner

## 📋 Description

A polished, fully responsive portfolio landing page. Sections: hero, about, skills, projects grid, contact. Mobile-first, 8px spacing system, 2 fonts max.

## ✨ Features

- Hero with animated gradient text
- About section with stats
- Skills grid with tags
- Projects grid with hover cards
- Contact section with social links
- Fully responsive (mobile-first)
- Smooth scroll navigation

## 🚀 How to Run

Open `index.html` in any browser.
